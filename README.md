# ECU Diagnostic System

Программный комплекс для диагностики и калибровки ЭБУ автомобилей с ДВС.

Состоит из C++ бэкенда (сбор данных с адаптера, работа с БД DTC-кодов, HTTP API) и
десктопного интерфейса на PyQt5 (front/), который обращается к бэкенду по HTTP.

## Возможности

- Поддержка протоколов: OBD-II, KWP2000, CAN, UDS
- Адаптеры: ELM327 (Bluetooth/USB), J2534 PassThru
- База DTC: более 300 кодов с русским описанием, причинами и степенью тяжести
- Live-данные: обороты двигателя, скорость, температура ОЖ, положение дросселя, MAF и др.
- Редактор калибровок (Stage 1): угол зажигания, топливная карта, управление турбиной, ограничитель оборотов
- Резервное копирование и восстановление прошивки ЭБУ

> Чтение/запись прошивки и резервное копирование ЭБУ в текущей версии — демонстрационный режим
> (UI и API готовы, но реальный обмен данными с ЭБУ ещё не подключён). Не используйте эту версию
> для работы с реальным автомобилем.

## Требования

- Windows 10/11
- Visual Studio 2022+ (для сборки бэкенда через CMake)
- Python 3.10+
- SQLite3 (`sqlite3.h` / `sqlite3.lib` в `sqlite3/include` и `sqlite3/lib` — см. `build_main.bat`)
- Для J2534-адаптеров: драйвер производителя (например, `J2534_MongoosePro_JLR_x64.msi`,
  распространяется отдельно от репозитория — устанавливается вручную)

## Запуск

1. Установите Python-зависимости:
   ```
   pip install -r front/requirements.txt
   ```
2. Соберите бэкенд:
   ```
   build_main.bat
   ```
3. Запустите приложение:
   ```
   run.bat
   ```
